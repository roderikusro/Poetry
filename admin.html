🚀 Publikasikan ke GitHub

Perubahan via admin hanya tersimpan di browser ini (localStorage).
Untuk membuat perubahan muncul di semua device, unduh file data.js baru, lalu replace di folder project kamu dan push ke GitHub.

Setelah download → replace data.js → git add . → git commit -m "update" → git push

📦 Backup Data

Ekspor dan impor data puisi dalam format JSON (untuk backup/restore).

🗑️ Reset Data

Kembalikan semua puisi ke data bawaan (default). Puisi yang ditambahkan lewat admin akan dihapus.

🔑 Ubah Password Admin

Password admin tersimpan di data.js. Ubah langsung di file data.js variabel ADMIN_PASSWORD.
